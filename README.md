# Портфолио Рамины Зунуновой

Одностраничный сайт-портфолио начинающего разработчика. Только HTML, CSS и JavaScript — без библиотек и фреймворков.

## Как запустить

1. Распакуйте папку `portfolio`.
2. Откройте файл `index.html` двойным щелчком (откроется в браузере).
3. Интернет нужен только для шрифта Manrope. Без интернета сайт работает со шрифтом Arial.

## Структура проекта

```
portfolio/
├── index.html        — разметка страницы (6 разделов)
├── css/style.css     — все стили в одном файле
├── js/script.js      — функции JavaScript
├── assets/           — фотографии и афиши
├── README.md         — этот файл
└── DESIGN.md         — описание дизайна для Figma
```

## Разделы сайта

Главная · Обо мне · Навыки · Проекты · Опыт и деятельность · Контакты.
В HTML использованы теги `header`, `nav`, `main`, `section`, `footer`.

## Функции JavaScript (файл js/script.js)

Первые четыре — обязательные по заданию. Пятая и шестая — дополнительные.

| № | Функция | Что делает | Как работает |
|---|---------|-----------|--------------|
| 1 | `setupMobileMenu()` | Открывает и закрывает меню на телефоне | Кнопка «Меню» переключает класс `open` у списка ссылок (`classList.toggle`). Меню закрывается после выбора пункта. |
| 2 | `setupProjectFilter()` | Показывает проекты по категориям | У каждой кнопки есть `data-filter`, у каждой карточки — `data-category`. Совпадение — карточка видна, нет — получает класс `hidden`. |
| 3 | `setupModal()` | Открывает окно с подробностями проекта | Кнопка «Подробнее» берёт данные из объекта `projectsInfo` по `data-id` и открывает `<dialog>` методом `showModal()`. Закрывается крестиком, Esc или кликом по фону. |
| 4 | `setupContactForm()` | Проверяет контактную форму | При отправке проверяет имя (от 2 символов), email (есть `@` и точка) и сообщение (от 10 символов). Под полем показывает ошибку или общее сообщение об успехе. |
| 5 | `setupBackToTop()` | Показывает кнопку «Вверх» | При прокрутке (событие `scroll`) проверяет `window.scrollY > 300` и переключает класс `visible`. Плавность — CSS (`transition`, `scroll-behavior: smooth`). |
| 6 | `setupThemeToggle()` | Переключает светлую и тёмную тему | Ставит на `<html>` атрибут `data-theme="dark"` или `"light"`. CSS при `[data-theme="dark"]` заменяет значения цветовых переменных. Выбор запоминается в `localStorage`. |

Все функции вызываются в конце файла.

## Что важно знать для защиты

- Форма **учебная**: проверка работает, но сообщение никуда не отправляется. Для отправки нужен сервер.
- Все ссылки в меню ведут к якорям (`href="#about"` ↔ `id="about"`).
- У каждого поля формы есть `<label for="...">`, связанный с `id` поля.
- Анимации — только CSS: появление главного блока, поднятие карточек при наведении, открытие окна.
- Адаптивность — один блок `@media` для планшета (900px) и один для телефона (700px).

## Проверка работоспособности

Проверено автоматически в браузере Chromium (ширина 1280 px и 375 px):

- Меню на телефоне открывается, закрывается и закрывается после выбора пункта.
- Фильтр: «Все» — 5 проектов, «Хакатоны» — 2, «Дизайн» — 2, «Клуб» — 1.
- Модальное окно открывается с нужными данными, закрывается крестиком и клавишей Esc; картинка показывается только у афиш.
- Форма: пустые поля — три ошибки; неверный email — ошибка; верные данные — сообщение об успехе.
- Кнопка «Вверх» плавно появляется после прокрутки и возвращает наверх.
- Тёмная тема включается, выключается и сохраняется после обновления страницы.
- Горизонтальной прокрутки нет (на 1280 px и 375 px).
- Все изображения загружаются, все якорные ссылки ведут к существующим разделам.
- Ошибок JavaScript в консоли нет, у всех полей формы есть `label`.

Перед защитой откройте сайт сами и пройдите по всем кнопкам.
